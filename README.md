# Laravel Database Migrations & Optimization Skill

An AI agent skill for designing schemas, writing safe migrations, indexing strategies, and query optimization.

## Topics Covered

- Migration patterns (pivot tables, polymorphic, soft deletes)
- Zero-downtime schema changes (add/rename columns, concurrent indexes)
- Indexing strategies (composite, fulltext, when to/not to index)
- Query optimization (EXPLAIN, chunking, eager loading, subquery selects, upsert)
- Factories and seeders with state methods

## Installation

```bash
npx skills add neuraliq/laravel-database-migrations
# or
php artisan boost:add-skill neuraliq/laravel-database-migrations
```

## Compatibility

Claude Code, Cursor, Windsurf, GitHub Copilot

## Requirements

Laravel 11+, MySQL 8+ or PostgreSQL 14+
